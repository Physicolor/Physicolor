<h1 align="center">DeepSeek Harness plugins</h1>

<p align="center">
  <strong>DSH Design System</strong> — one interface language, from the rule to the running product.<br>
  Two repositories that are worth installing together:
</p>

| Repository | Role | The question it answers |
| --- | --- | --- |
| [**dsh-design-resources**](https://github.com/Physicolor/dsh-design-resources) · [site](https://physicolor.github.io/dsh-design-resources/) | Spec, seat directory, design tokens, the official icon set, a reusable-source knowledge base and a live component gallery | How the interface **should** be built — how big a control is, how wide a gap is, how long a motion lasts, how an icon is drawn |
| [**dsh-ui-harmonizer**](https://github.com/Physicolor/dsh-ui-harmonizer) · [npm](https://www.npmjs.com/package/dsh-ui-harmonizer) | A client-only DSH bundle plugin: normalises the official UI, reconciles installed plugins, runs a read-only compatibility audit | How it **actually** turned out — and what it could not fix |

The spec obliges nobody to change their code; the plugin makes conflicts visible, explainable and one click from an issue.
